# ❤️ Heart Disease Prediction using Logistic Regression

Predicting whether a person has heart disease from health and lifestyle indicators, using the **CDC 2020 heart-disease dataset (319,795 records, 18 features)**.

## Overview

Early detection of heart disease saves lives. This project cleans, explores and visualises a large public-health dataset — BMI, smoking, alcohol use, stroke history, physical and mental health days, general health, sleep time and more — and trains a **Logistic Regression** classifier on the binary target `HeartDisease`.

## Steps

1. Data loading, cleaning and encoding of categorical variables
2. Exploratory analysis and visualisation of risk factors
3. Train–test split and Logistic Regression model
4. Evaluation with accuracy, confusion matrix, precision, recall and F1

## Results

- **Accuracy: 91.5%**
- Precision 0.92 and recall 0.99 for the non-disease class
- Recall for the heart-disease class is much lower, because the dataset is heavily imbalanced. The report discusses this and how resampling or class weights would improve detection of positive cases — the more important error to avoid in a medical setting.
